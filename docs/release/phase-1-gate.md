## Caveats Idan should read

- **Criterion 2 is measured on 12-round runs**, but the toy players see is 5 rounds sampled from that curve (ADR-030). Since CON-06
  the toy also scales each map's demand and quota (ADR-032), which full runs do not. A pass means the archetypes are viable in the
  sim, not that the toy is balanced. The toy's own report ([`toy-con-06.md`](../balance/toy-con-06.md), 2,000 seeds per bot at
  `8274c2c`) has all five archetypes at 45–57% and the no-cards bot at 20.1%.
- **The feel report predates CON-06.** It found 38% of toy rounds gridlocked. In the soak at 061bb07, 348 of 2397 toy rounds
  gridlocked (15%), against 854 of 2265 (38%) before #87. Idan's playtest is on the new curve.
- **The toy run lasts about 3 minutes.** Poki's 3-minute mark falls at the end of a first run, so criterion 4 depends on how many
  players start a second run.
