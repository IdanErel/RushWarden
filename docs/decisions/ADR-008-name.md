# ADR-008: The game is named Rushwarden

Status: Accepted · 2026-10-10 · Idan chose it on the name decision

The Phase 0 screen (`docs/setup/name-search.md`) found "Gridlock Royale" risky: a crowded word
with same-theme games, a pending GRIDLOCK board-game application, and a "Royale" echo of Clash
Royale on a card game. Rushwarden had no store or US trademark hits and its domains looked free.

- Product, store and copy name: **Rushwarden**. Package scope `@rushwarden/*`.
- Bundle/package ID: `com.rushwarden.game`. Domain: `rushwarden.com` (Idan registers it).
- `docs/gdd.md` stays the brief as written; wherever it says "Gridlock Royale" read "Rushwarden".
  Gameplay terms that use the word gridlock (the gridlock detector, the black share glyph, the
  "Gridlock Drill" boss) are mechanics, not the title, and stay.
- Before spending on the name, Idan gets a trademark attorney's clearance including EU and UK,
  which this screen could not check.
