# Rushwarden

- Read `docs/gdd.md` before any task. It is the binding spec (the game was renamed from
  "Gridlock Royale" to Rushwarden in ADR-008). Section 13 defines roles, ownership and rules.
- Run `pnpm lint` and `pnpm test` (plus `pnpm typecheck`) before calling work done.
- One task, one branch from `main`, one PR using `.github/pull_request_template.md`. Never self-merge (ADR-005).
- Decisions the brief does not cover go in `docs/decisions/` as an ADR.
- Spend, store consoles, public posts and pricing need Idan's go-ahead.
